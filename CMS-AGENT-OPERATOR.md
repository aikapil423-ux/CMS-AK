# CMS live website operator

Voice fix (2026-10-26): a completed recognition turn now sends its final transcript automatically, once, without the Send button. Interim text is not executed; errors, Stop, closing the modal and manual transcript edits cancel automatic submission. Existing save/review approvals still apply. Hindi speech spellings for register/complaint/page are normalized locally. Transient model HTTP 502/503/504 failures receive one retry within the same timeout; quota/provider failures are reported distinctly. The provider returned HTTP 503 during diagnosis, despite model discovery succeeding. Automated recognition-event tests cover auto-send, multiple segments, duplicate end events, cancellation and spoken Stop; physical microphone recognition remains browser/device dependent.

The agent re-reads rendered controls on every command and before each action. Routes refresh from app source, the production app-paths manifest and visible internal links. New native inputs, selects, links and buttons therefore do not need a new command dictionary. Dynamic record URLs are discovered from visible links; the agent never guesses record identifiers.

Use native labels/aria-label (or data-agent-label) on controls, required/aria-required for mandatory fields, and role=tab for tabs. Unlabelled, canvas and custom widget controls need an accessible adapter. Hidden, disabled and password controls are excluded. Agent UI is excluded using data-cms-agent-ui.

For flexible natural-language planning configure GEMINI_API_KEY. CMS_AGENT_MODEL optionally pins a model; otherwise the server discovers a supported Flash model from the provider catalogue. GET /api/cms-agent/operator?health=1 verifies discovery (not generation). Without a key, local page, explicit field/value, search and button commands work. Configured planning sends the visible page fields and recent conversation to the configured Gemini model; do not enable it for real case data without your organization's authorization. No key is exposed to the browser.

Examples: `FIR register kholo`, `name = Ramesh, mobile = 9812345678`, `क्या जानकारी चाहिए`, `Save`, then `हाँ` or `cancel`. Buttons require confirmation; fields may trigger the website's existing draft autosave. Save completion must be confirmed by the website receipt/record. Multi-step commands use then/phir/फिर/uske baad and retain remaining steps across confirmations. The AI planner can request another planning pass after navigation/control changes. Each run is bounded to eight steps, repeated plans stop, failures stop the queue, and controls are re-read before execution.

Attachments: TXT/CSV/Markdown/JSON and compressed DOCX text are read locally. PDF/images/audio use the server Gemini extraction endpoint. Maximum 8 MB per file, 40,000 extracted characters, latest three attachments in memory. Extracted text is shown for review and treated as untrusted source data, not instructions. Encrypted/unsupported/unreadable files report failure. Custom controls with ARIA button/combobox/option/menuitem/checkbox/switch roles are discovered. Use data-agent-operation="read" only for controls that cannot write records; all other buttons require approval.

This feature discovers the current UI; it does not rewrite its own source, bypass access controls or guarantee support for every future widget. Existing demo authentication and legacy agent API are not production authorization. Do not expose the model planning endpoint publicly without adding your deployment's authenticated session/rate limiting.

Enquiry and FIR template builders register adapters that expose receipts only after their existing save services succeed. Missing receipts stop the queue with an unverified outcome instead of reporting a save. Opening a save dialog is classified as a read action. These receipt integrations were typechecked, but this QA did not persist new case records.

Planning minimizes unrelated field values and excludes recognized sensitive identifier fields. This is data minimization, not complete anonymization. Source previews include extracted-text line numbers, not claimed PDF page citations. Helpful/unhelpful feedback and operation-only quality reports stay in memory until exported; they do not automatically train the model.
